# PRIMEVEST visual identity

- `primevest-logo.png`: selected AI-generated concept and wordmark reference.
- `primevest-mark.svg`: vectorized rendition of the selected monogram, derived from that concept for use at small sizes. `src/components/brand.tsx` uses the same silhouette, with a live text wordmark; `src/app/icon.svg` uses the mark as the browser icon.
- Colours: near-black #08090b, lime #c8f751 and green #27ec65. Existing asset marks and currency flags retain their own colours.

The identity is a preliminary design, not a trademark clearance or confirmation that PRIMEVEST and its domains are available. Obtain legal, trademark, company-name and domain checks in all intended markets before a public launch. Existing internal storage and session keys retain their historical `vanta` names for compatibility; they are not the public brand.
