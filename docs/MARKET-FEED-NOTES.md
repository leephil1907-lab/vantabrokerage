# Homepage market feed notes

On 1 November 2026 the deployed `/api/markets` returned HTTP 200 with an empty `markets` array. The corresponding code asks the connected database for enabled trading-pair definitions, and returns a row per enabled pair even if a provider quote fails. This response is therefore consistent with no enabled pairs in the database reached by that deployment (including a potentially wrong database/environment). Without Vercel project and database access, the exact environment and cause cannot be verified. Do not run seeds or migrations on customer databases without review and authorization.

The separate CoinGecko discovery endpoint returned 250 crypto assets. The homepage can show Bitcoin, Ethereum and other **USD reference prices** and a real CoinGecko price-history chart when configured quotes are unavailable. These are not executable quotes, order-book liquidity, bid/ask prices or evidence that trading is operational. Delayed and provider-outage states remain visible. Market reference fallbacks do not modify the database or bypass the existing order and deposit safeguards.

To investigate the configured feed, verify the deployed commit and runtime `DATABASE_URL` target without exposing credentials, inspect enabled instrument definitions and provider/network logs, then agree a non-destructive fix. Confirm separately that each desired market and its provider are appropriately configured and permitted. `scripts/test-theme-and-reference.mjs` and `scripts/test-empty-markets.mjs` use an isolated empty database; the former mocks the data feed for deterministic UI checks, never for production prices.
